title: Start a form
description: Choose a blank form or a starter template and set its UI library.
---

Templates provide fields, layout, and example values. Choose one when its structure is close to what
you need, or start blank for full control.

## Choose a template

1. Open **Workspace** in the sidebar.
2. Select **Create Form**.
3. Optionally enter a name. Leave it empty to use the template's title, or **New form** for a blank form.
4. Select **Material**, **Ng Zorro**, or **Bootstrap**, or leave **UI Library** empty for Vanilla.
5. Click an example under **Quick Start**, or **Start with a blank form**, to create it immediately.

The new form opens in **Builder**. Select a field to replace its example content, remove fields you do not need, or add new fields from **Add**.

Templates work with any of the available libraries. Choose the library before clicking an example;
the library cannot be changed after creation.

## Available templates

The Form Editor provides these starters:

| Template           | Good starting point for                        |
| ------------------ | ---------------------------------------------- |
| **Starter Form**   | Learning the editor with a simple contact form |
| **Expense Report** | Expense details, amounts, and receipt flags    |
| **Contact Us**     | Contact information, subject, and message      |
| **Profile Update** | Personal details, bio, and a profile picture   |

Templates are examples, not fixed forms. Rename the form and change any field or value after creating it.

**Send Message** and **Update Profile** validate the example locally; they do not send data to a
server. Profile pictures are saved with the local form model and are limited to 2 MB. Connect your
own submission and upload handlers when using an exported form in an application.

## Start with a blank form

Choose **Start with a blank form** when none of the templates matches your workflow. Select the UI library before
creating the form; it cannot be changed later. [Compare UI libraries](/ui-libraries/) before deciding.

## Templates and presets

A template creates a complete form. A preset adds one preconfigured field to an open form. See
[Add and configure fields](/guides/add-and-configure-fields/) for the preset workflow.
