---
title: Demo UI Profiles
description: Compare the UI-library configurations included in the Studio demo.
---

These profiles are the UI-library configurations included in the hosted ngx-formly Builder
application. They describe the demo's authoring support, not a universal limit on
the editor framework or every capability in upstream ngx-formly.

Choose the UI library that matches the consuming Angular application's design system. The choice
controls available fields, properties, containers, and exported type names, and cannot be changed
after the form is created.

| Library                               | Choose it when                                                           | Coverage                                                                                         |
| ------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| Vanilla (no library)                  | You want native HTML controls without a UI library                       | Input, number, textarea, checkbox, select, and groups                                            |
| [Material](/ui-libraries/material/)   | You want Material controls and richer layouts                            | Standard controls plus postal code, button group, markdown, cards, tabs, steppers, and repeaters |
| [Ng Zorro](/ui-libraries/ng-zorro/)   | Your application uses the standard `@ngx-formly/ng-zorro-antd` field set | Ng Zorro controls and groups                                                                     |
| [Bootstrap](/ui-libraries/bootstrap/) | Your application uses the standard `@ngx-formly/bootstrap` field set     | Bootstrap controls and groups                                                                    |

**Material is the single Material-based profile in ngx-formly Builder.** It combines the standard
Formly Material controls with the builder's additional types. Exports using those additional types
require their matching runtime components and configuration; the complete profile is not currently
published as a standalone public package.

Templates work with any of the available libraries. Leave the library empty to use Vanilla, or
select the library that supports your fields. To use another library later, create a new form and manually
rebuild or import a compatible configuration; Studio does not convert existing forms between
libraries.

Styling controls are documented in [Layout and styling](/guides/form-layout-and-styling/).
